# Q/C 记账法与复制率硬门槛
Q_chars = 所有【[Q]…[/Q]】字符数（不含空格/换行）  
C_chars = 所有【[C]…[/C]】字符数  
Total_chars = Q_chars + C_chars  
复制率 = Q_chars / Total_chars  

- 章级硬门槛：复制率 ≥ max(0.90, copy_ratio_target_p)（默认 0.92）。  
- C 占比（全章）≤ 0.10（理想 ≤ 0.05）。  
- 章字数 ≥ 2000；不足需续写补齐。

引用与连接标注
- 逐字引用片段（必用）：【[Q 包=__ 片段ID=__] …逐字原文… [/Q]】  
- 新写连接/转场/指代修正（最小编辑）：【[C] …新写过渡句… [/C]】  
- 【[Q]】内部一律零改写。

# 不引（no_quote）强检查
- 覆盖层指定的不引节拍：正文中不得出现【[Q]】。  
- 发现违规：立即将该处改为【[C]】重写并复算复制率（仍须 ≥ 0.90）。  
- 建议把不引控制为短镜头/短桥（100–150 字），其余节拍用 2–3 个 FRAG 连缀拉高 Q。

# 知识提炼流水线（供准备 06–10 包时遵循）
1) 预清洗：统一标点；去冗空格；保留章节/场景线索。  
2) FRAG 细分：每 150–400 字一段；统一标题与标签；生成片段ID。  
3) 锚点与关键词：每段提取开头 12 字 + 3–6 个关键词。  
4) 05 索引：登记 片段ID/包名/页锚/关键词/标签；行号兜底也要登记。  
5) 包内 TOC：06–10 顶部建立 “节拍关键词 → 片段ID” 的 TOC，覆盖本批 80% 节拍。  
6) 稽核：ID 不重复；标签必填；关键词≥3；每包 2–3 万字；功能/POV/情绪均衡；同功能做 α/β/γ 变体。

# 工程守则（确保复制率 ≥ 90%）
- 节拍冗余：每节拍准备 6–10 个 FRAG 候选；每章目标 Q≥1800（章=2000 字、p=0.90）。  
- 系统/提示短小稀疏：system_c_budget_per_chapter=100（把 C 留给必要连接）。  
- 不引节拍短桥处理：100–150 字；其余用 2–3 FRAG 连缀拉高 Q。  
- 低于阈值即回写：块级复制率<0.90 或 C/总>0.10 → 当块换 FRAG/减少【[C]】并重算。  
- 多样性：同一包连续主引用 ≤ 2；辅引用 ≤ 2；跨 POV/功能/情绪轮换。
