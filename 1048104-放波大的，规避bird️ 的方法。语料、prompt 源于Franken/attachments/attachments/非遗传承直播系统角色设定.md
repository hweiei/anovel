# 《非遗传承直播系统》爆款标题与角色设定

## 一、爆款标题（番茄风格）
### 主标题：《左手非遗：我的直播系统连接古今》  
**副标题**：破产后修复抗战文物，全网跪求我开付费课  

### 标题解析：  
- **强冲突**："左手非遗"突出残疾反差，"破产"制造生存危机  
- **系统金手指**："连接古今"暗示文物记忆能力，符合番茄"功能明确"要求  
- **结果导向**："全网跪求付费课"预示直播成功，满足爽点预期  

## 二、主要角色设定（3名）

### 1. 秦墨（主角）  
**外貌**：左手指关节变形，常穿洗褪色的靛蓝工装，腰间挂爷爷传的铜刻刀  
**背景**：考古系休学学生，因车祸导致左手神经损伤，继承爷爷的晋商密箱后激活系统  
**性格**：隐忍坚韧，直播时话少但专注，面对质疑会用实力打脸  
**动机**：修复密箱中抗战时期的缠花簪，完成爷爷"非遗不能断"的遗愿  

### 2. 晋小商（系统精灵）  
**形象**：Q版晋商掌柜，戴瓜皮帽，算盘不离手，说话带平遥口音  
**功能**：发布山西非遗任务，奖励需用"守护值"兑换，性格吝啬但护主  
**金句**："守护值不够？拿你直播间打赏来抵嘛！"  
**关键任务**："修复应县木塔模型，解锁古建筑线直播权限"  

### 3. 苏杏儿（女主）  
**身份**：大同缠花非遗工坊继承人，抖音小网红（粉丝5万）  
**冲突点**：初期直播连麦diss秦墨"蹭非遗流量"，后发现其真才实学  
**技能**：能盲缠"凤凰三点头"纹样，直播时负责互动控场  
**成长线**：从抵制直播到创新"缠花+汉服"带货，年销售额破千万  

## 三、小白化次要角色（5名）

### 1. 王大勇（景区保安）  
**标签**：憨厚杠精  
**外貌**：微胖，制服袖口总沾着油漆（兼职文物修复工）  
**"小白"行为**：章96故意断秦墨直播信号："非遗直播就是瞎折腾！"  
**转变**：看到秦墨单手修复砚台后，每天偷偷送景区废弃木料  

### 2. 李萌萌（00后学徒）  
**标签**：饭圈少女  
**口头禅**："哥哥的翎子功比爱豆舞台还帅！"  
**功能**：用饭圈话术解读非遗（如"晋剧水袖舞=古风版爱豆直拍"）  
**关键剧情**：误将修复漆料当奶茶喝，引发"非遗安全科普"直播  

### 3. 张教授（文物专家）  
**标签**：傲娇学者  
**特点**：初期连麦质疑："这不是传统技法！"，实则默默收藏秦墨直播回放  
**隐藏身份**：秦墨爷爷的学生，暗中提供考古资源  

### 4. 赵小胖（美食主播）  
**标签**：吃货憨憨  
**直播名言**："这非遗能不能吃？不能吃我走了啊！"  
**功能**：联动直播山西非遗美食（如太原头脑、稷山麻花），带动带货  
**名场面**：吃"头脑"被药材呛到，弹幕刷屏"保护我方吃货"  

### 5. 陈建国（退休教师）  
**标签**：固执老派  
**偏见**："直播就是哗众取宠，非遗就该在博物馆里待着"  
**转变**：章215跨国对决时，带头举"中国漆艺正统"灯牌  

## 四、角色关系图谱  
```  
秦墨（主角）  
├─ 师徒：张教授（指导修复）  
├─ 欢喜冤家：苏杏儿（直播搭档）  
├─ 监管者：晋小商（系统精灵）  
└─ 粉丝代表：王大勇（保安）、李萌萌（学徒）、赵小胖（吃货）  
```  

### 角色设计原则：  
1. **背景绑定山西**：所有角色职业/籍贯与非遗项目强关联  
2. **小白角色功能单一**：如赵小胖仅负责美食线互动，避免复杂成长  
3. **冲突即时化解**：次要角色与主角的矛盾3章内解决，符合番茄快节奏要求
