包说明：Frankentexts 处理提示模板包
包含文件：
- prompt_template.txt      （最短版模板，适合快速发送）
- full_prompt_template.txt （完整高级版模板，可精确控制处理）
- example_request.txt      （示例请求）
- README.txt               （本说明）

使用方式：
1) 下载并解压本包
2) 上传你要处理的小说到对话（或在本地使用脚本）
3) 复制 prompt_template.txt 或 full_prompt_template.txt 中的内容，按需填写参数，连同小说文件一起发送给我
4) 我会在收到文件和指令后返回 JSONL/CSV/ZIP 可下载链接

版权与隐私：请确保你有权上传与处理该小说文件。

技术支持：如果你需要将模板自动化整合进本地脚本或 GUI，我可以帮你生成对应代码或批处理脚本。
