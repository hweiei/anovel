# 预料库片段模板（1-8号文件通用）

> 与主提示词 v400 完全对齐

## 文件头信息

```markdown
# 预料库 [编号]：[类型名称]

**库ID**: LIB-[01-08]
**类型**: [古风武侠/都市情感/玄幻修真/悬疑推理/科幻未来/历史架空/日常对话/环境描写]
**片段数量**: [数字]
**适用场景**: [简述适用的情节类型]
**语体风格**: [古风/白描/轻喜/热血/冷峻/温柔/...]
**版本**: v[X.X]
**最后更新**: [YYYY-MM-DD]

---
```

## 片段格式规范（与主提示词对齐）

每个片段必须遵循以下格式：

```
=== FRAGMENT ===
TEXT: <片段正文（80–300字，纯文本）>
META:
  roles: 主/配角名（可多）
  scene: 场景/地点/时间（如：雨夜·茶馆·子时）
  emotion: 情绪/气质（如：压抑/温柔/决绝）
  conflict: 冲突类型（如：追逐/潜伏/争吵/战斗/自省）
  style: 语体（如：古风/白描/轻喜/热血）
  tags: 关键词若干
  quality_score: <可选，1-10分，用于优先选择高质量片段>
CONFLICTS:
  - name_conflict: <若人名与设定不同，写出差异；否则留空>
  - timeline_hint: <若时间线受限，写出提示；否则留空>
  - pov_hint: <若视角受限（第一/第三人称），写出提示；否则留空>
```

## 片段筛选规则

### 筛选优先级
| 优先级 | 条件 |
|--------|------|
| 高优先 | emotion/conflict/scene 完全匹配 |
| 中优先 | style 兼容 + tags 部分匹配 |
| 低优先 | 仅 tags 匹配 |

### 排除条件
- name_conflict 非空且无法通过简单替换解决
- timeline_hint 与当前章节时间线冲突
- pov_hint 与当前章节视角不兼容

## 元信息标签体系

### 场景类型 (scene)
```
战斗场景: 对决·擂台·正午 | 夜袭·山林·子时 | 围攻·城门·黄昏
情感场景: 告白·月下·深夜 | 离别·渡口·清晨 | 重逢·故地·午后
日常场景: 闲聊·茶馆·午后 | 用餐·酒楼·傍晚 | 修炼·密室·深夜
悬疑场景: 调查·现场·白天 | 追踪·暗巷·深夜 | 对峙·密室·子时
```

### 情绪标签 (emotion)
```
正面: 喜悦, 兴奋, 温柔, 感动, 释然, 希望, 骄傲
负面: 悲伤, 愤怒, 恐惧, 绝望, 嫉妒, 愧疚, 焦虑
复杂: 纠结, 怀旧, 释怀, 决绝, 隐忍, 疯狂, 麻木
```

### 冲突类型 (conflict)
```
外部冲突: 追逐, 战斗, 对峙, 围攻, 逃亡, 营救, 潜伏
内部冲突: 自省, 抉择, 挣扎, 觉醒, 崩溃, 重生
关系冲突: 争吵, 误解, 背叛, 和解, 告白, 离别
```

### 语体风格 (style)
```
古风: 文言倾向，意境优美，用典雅致
白描: 简洁克制，不加修饰，冷静客观
轻喜: 幽默诙谐，节奏轻快，对话俏皮
热血: 激昂澎湃，节奏紧凑，情感强烈
冷峻: 硬朗简练，氛围压抑，张力十足
温柔: 细腻婉转，情感绵密，氛围温馨
```

## 预料库分类建议

### 01_预料库_古风武侠.md
- 适用：武侠、仙侠、古代言情
- 特点：文言倾向、意境描写、江湖气息

### 02_预料库_都市情感.md
- 适用：都市、言情、职场
- 特点：现代语境、情感细腻、生活化对话

### 03_预料库_玄幻修真.md
- 适用：玄幻、修真、异能
- 特点：战斗描写、境界突破、功法描述

### 04_预料库_悬疑推理.md
- 适用：悬疑、推理、惊悚
- 特点：线索铺设、氛围营造、心理描写

### 05_预料库_科幻未来.md
- 适用：科幻、末世、赛博朋克
- 特点：科技元素、未来感、硬核描写

### 06_预料库_历史架空.md
- 适用：历史、架空、宫斗
- 特点：时代感、权谋描写、礼仪细节

### 07_预料库_日常对话.md
- 适用：所有类型
- 特点：通用对话、日常互动、过渡场景

### 08_预料库_环境描写.md
- 适用：所有类型
- 特点：场景描写、氛围渲染、意境营造

## 片段提取提示词

用于从现有小说中提取片段：

```
请阅读以下小说文本，从中提取若干段落，每段80-300字，内容完整且富有情感和冲突。

对于每个提取的片段，请按照以下格式输出：

=== FRAGMENT ===
TEXT: <片段正文（80–300字，纯文本）>
META:
  roles: 主/配角名（可多）
  scene: 场景/地点/时间
  emotion: 情绪/气质
  conflict: 冲突类型
  style: 语体
  tags: 关键词若干
  quality_score: 1-10分
CONFLICTS:
  - name_conflict: <若人名与设定不同，写出差异；否则留空>
  - timeline_hint: <若时间线受限，写出提示；否则留空>
  - pov_hint: <若视角受限，写出提示；否则留空>

提取要求：
1. 优先选择情感饱满、冲突明显的段落
2. 避免选择过于依赖上下文的片段
3. 确保片段可独立理解
4. 标注所有可能的冲突点
5. 质量评分需客观公正
```

## 占比约束提醒

生成章节时必须遵守：
- 约 92% 直接拼接自 1–8 号预料库
- 约 8% 为原创（仅连接/过渡/最小改写）
- 单一预料库贡献 ≤30%
- 每章覆盖 ≥5 个不同预料库
- 建议每章可用片段池 ≥100 个
