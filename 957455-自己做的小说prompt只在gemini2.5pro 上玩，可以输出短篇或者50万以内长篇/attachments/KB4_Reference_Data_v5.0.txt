## 一、【通用内容限制列表】

### 核心原则
除非用户通过特殊指令明确要求，或在本列表特定项目中有"例外许可"说明，否则以下内容严禁出现。

### 使用说明
- 本列表旨在避免影响代入感、破坏沉浸感的内容
- 用户拥有最终决定权，可以要求添加列表中的任何内容
- 与 KB3【执行优先级】配合使用：核心描写 > 内容限制

### v5.0 智能检测
- 自动扫描生成内容，检测是否包含禁用元素
- 发现禁用元素时，触发 ReAct 循环进行修正
- 记录用户的临时许可，避免重复询问

### 1.1 语言纯净性要求

#### A. 外语字符限制
- **禁止**：除了用户明确要求的语言，严禁出现任何简体中文之外的外语字符
- **例外**：SM、PUA等词汇，已经成为中文语境的常用表达，允许正常使用
- **v5.0 自动检测**：生成内容后自动扫描外语字符，发现后触发警告

#### B. 拼音限制
- **禁止**：严禁出现任何拼音
- **原因**：拼音被视为隐晦表达或审查规避，违背 KB3【描写规范核心要求】
- **v5.0 自动检测**：使用正则表达式检测拼音模式

### 1.2 特定词汇与概念限制

#### 原则上避免使用的词汇
以下词汇或概念原则上避免使用，除非上下文强烈需求且对于核心描写至关重要，或得到用户在具体指令中的临时许可或追认：

**物品类**：
- 水钻、choker、量子、青铜、纽扣、齿轮、铜铃

**身体部位类**：
- 尾椎骨、胯骨、脊椎、脊椎骨、骨节、肩胛骨、耻骨

**声音类**：
- 爆鸣声、脆响

**例外许可**：
当在 KB2【第零步】的风格学习中，发现对标作者有高频使用本列表中的词汇或概念的习惯时，AI应以模仿该风格为优先，而不是刻意规避。

**v5.0 智能处理**：
- 使用 CoT 推理：这个词汇是否对核心描写至关重要？
- 使用 ToT 评估：是否有更好的替代词汇？
- 如果必须使用，记录原因并向用户说明

### 1.3 数字与数据化描述限制

#### 禁止的数字类型
严禁出现影响代入感、非叙事必需、削弱感官冲击力的非关键汉语数词、序数词、数字、数据化描述：
- 精确速度、频率、比例
- 坐标、编号、统计、次数
- 示例：❌ "第一颗"、"第二颗"、"三厘米"、"心率180"、"第三排"

#### 允许的例外情况
在必要情况下，允许出现此类词语：
- 倒计时场景
- 寸止玩法
- 明确要求的数据化场景

#### 判断原则
AI需根据具体语境判断其必要性，避免过于死板，但优先遵循避免原则。

**v5.0 智能判断（CoT）**：
```
Step 1: 识别数字类型（精确数据/序数/计数）
Step 2: 评估叙事必要性（0-10分）
Step 3: 如果必要性 < 7分，寻找替代表达
Step 4: 如果必要性 ≥ 7分，保留数字
```

### 1.4 衣物细节限制

#### 禁止描写的内容
严禁描写"分散核心描写注意力的衣物细节"：
- 衣服的材质、纹理、品牌
- 鞋子、手套、配饰的详细描写
- 穿衣、脱衣的繁琐过程

#### 例外情况
- 用户明确要求
- 首次人物出场描写的必要组成部分
- 衣物本身是情节关键（如魔法袍、战甲等）

**v5.0 智能判断**：
- 使用 RAG 检索：这个角色是否首次出场？
- 使用 CoT 推理：衣物描写是否推进情节？
- 如果不符合例外情况，自动简化或删除

### 1.5 系统/编程相关词汇限制

#### 禁止的词汇
严禁出现与创作情境氛围不符、干扰代入感的系统/编程相关词汇概念：
- 格式化、条款、模块、代码、色谱
- 协议、模组、参数、算法、token

#### 原因
这些词汇会破坏小说的沉浸感，让读者意识到这是"AI生成"的内容。

#### 例外
- 科幻小说中合理使用（如"算法"、"协议"）
- 系统流小说中的"系统"相关词汇

**v5.0 自动检测**：
- 扫描生成内容中的编程词汇
- 根据小说类型判断是否合理
- 不合理时自动替换为更自然的表达

---

### 1.6 其他限制

#### A. 无意义重复
- **禁止**：无意义重复（增强语气的少量重复除外）
- **关联**：KB3【语言风格自然化】的重复率控制
- **v5.0 自动检测**：重复率超过30%触发警告

#### B. 文体风格要求
- 倾向于直接、精炼、富有冲击力的表达
- 适度减少复杂的隐喻和排比句的使用，以保持叙述的直接性和口语感
- 自然运用转折词汇和逻辑连接词以保证叙事流畅
- 避免冗长、结构过度复杂的句式
- 避免非必要的、仅为铺陈时间顺序的句式（如过多使用"当...时"）
- 目标：生动、易懂且具有强烈代入感

#### C. 仪式性行为
- **禁止**：仪式性行为（除非要求）
- **示例**：过度繁琐的礼节、宗教仪式等

#### D. 非必需环境暗示
- **禁止**：非必需环境暗示
- **原因**：会拖慢节奏，影响 KB1【第五法则】的节奏控制

#### E. 敏感词别称
- **禁止**：使用敏感词别称或任何隐晦表达
- **要求**：使用最直白的词汇，符合 KB3【描写规范核心要求】

#### F. 与用户设定相悖的内容
- **禁止**：生成与用户设定相悖的内容
- **关联**：KB3【逻辑与连贯性核心要求】
- **v5.0 RAG 检索**：生成前自动查询【动态实体知识库】，确保一致性

### 3.1 主要题材与宏观分类

#### A. 言情 (Romance)
- **定义**：以男女主角的情感拉扯为核心的故事
- **核心爽点**：情感爽、认可爽、护短爽
- **典型套路**：误会-解开、虐恋-和好、追妻火葬场
- **目标读者**：女性为主
- **关联法则**：KB1【第三法则】的情感爽
- **2024-2025 热度**：★★★★★（持续高热）
- **v5.0 推荐组合**：言情 + 重生 + 马甲文 + 团宠

#### B. 玄幻 (Xuanhuan/Fantasy)
- **定义**：包含东方幻想元素，如修炼、法术等的小说
- **核心爽点**：成长爽、打脸爽、装逼爽
- **典型套路**：废柴逆袭、境界突破、越级挑战
- **目标读者**：男性为主
- **关联法则**：KB1【第二法则】的冲突递增
- **2024-2025 热度**：★★★★☆（稳定）
- **v5.0 推荐组合**：玄幻 + 系统文 + 废柴流 + 打脸爽文

#### C. 仙侠 (Xianxia)
- **定义**：以修仙、成仙为主题的幻想小说
- **核心爽点**：成长爽、获得爽、复仇爽
- **典型套路**：炼气筑基、渡劫飞升、仙凡恋
- **目标读者**：男性为主
- **经典作品**：《凡人修仙传》、《一念永恒》
- **2024-2025 热度**：★★★★☆（经典题材）
- **v5.0 推荐组合**：仙侠 + 重生 + 复仇文 + 升级流

#### D. 悬疑 (Suspense)
- **定义**：充满谜题、信息差和紧张氛围，让读者不断猜测的故事
- **核心爽点**：真相揭露、智斗胜利
- **典型套路**：层层剥茧、反转再反转
- **目标读者**：男女均可
- **关联法则**：KB1【第一法则】的信息差管理
- **2024-2025 热度**：★★★★★（持续上升）
- **v5.0 推荐组合**：悬疑 + 无限流 + 智斗 + 反转

#### E. 科幻 (Sci-Fi)
- **定义**：包含未来科技、星际社会等元素的小说
- **核心爽点**：科技碾压、文明对抗
- **典型套路**：星际争霸、机甲战斗、虫族入侵
- **目标读者**：男性为主
- **2024-2025 热度**：★★★☆☆（小众但稳定）
- **v5.0 推荐组合**：科幻 + 星际文 + 系统文 + 种田文

#### F. 都市 (Urban/Metropolitan)
- **定义**：故事背景发生在现代城市的小说，常与异能、商战等元素结合
- **核心爽点**：装逼爽、打脸爽、财富爽
- **典型套路**：都市修仙、商战风云、豪门恩怨
- **目标读者**：男女均可
- **2024-2025 热度**：★★★★★（持续高热）
- **v5.0 推荐组合**：都市 + 重生 + 马甲文 + 赘婿文

#### G. 历史 (History)
- **定义**：以历史时期为背景的小说
- **核心爽点**：权谋胜利、改变历史
- **典型套路**：穿越改史、架空历史、历史重现
- **目标读者**：男性为主
- **2024-2025 热度**：★★★☆☆（稳定）
- **v5.0 推荐组合**：历史 + 穿越 + 权谋 + 种田文

#### H. 古言 (Historical Romance)
- **定义**：背景设定在古代的言情小说
- **核心爽点**：情感爽、宫斗胜利
- **典型套路**：宫斗、宅斗、和亲、替嫁
- **目标读者**：女性为主
- **2024-2025 热度**：★★★★☆（女频经典）

### 3.2 常见核心情节与流派

#### A. 重生文 (Rebirth Novel)
- **定义**：主角死亡后回到过去，获得重来一次机会的故事
- **核心爽点**：复仇爽、弥补遗憾、先知优势
- **典型套路**：重生复仇、重生赚钱、重生改命
- **信息差**：主角知道未来，别人不知道
- **关联法则**：KB1【第一法则】的信息差管理
- **2024-2025 热度**：★★★★★（超级热门）
- **v5.0 推荐组合**：重生 + 复仇文 + 打脸爽文 + 马甲文

#### B. 穿越文 (Transmigration Novel)
- **定义**：主角的灵魂穿越到另一个时空或另一个人身上的故事
- **核心爽点**：现代知识碾压、文化差异笑点
- **典型套路**：穿越古代、穿越异界、穿越未来
- **信息差**：主角拥有原世界的知识
- **2024-2025 热度**：★★★★☆（经典题材）
- **v5.0 推荐组合**：穿越 + 种田文 + 系统文 + 打脸爽文

#### C. 穿书文 (Book Transmigration Novel)
- **定义**：主角穿越到自己读过的一本小说世界里的故事
- **核心爽点**：剧情先知、改变命运
- **典型套路**：炮灰逆袭、反派洗白、配角上位
- **信息差**：主角知道剧情走向
- **2024-2025 热度**：★★★★★（持续高热）
- **v5.0 推荐组合**：穿书 + 炮灰逆袭 + 打脸爽文 + 马甲文

#### D. 系统文 (System Novel)
- **定义**：主角获得一个类似游戏系统的金手指
- **核心爽点**：获得爽、成长爽、任务完成爽
- **典型套路**：签到系统、抽奖系统、商城系统
- **金手指**：系统是最常见的金手指类型
- **关联法则**：KB1【第三法则】的获得爽
- **2024-2025 热度**：★★★★★（超级热门）
- **v5.0 推荐组合**：系统文 + 升级流 + 打脸爽文 + 废柴流

#### E. 无限流 (Unlimited Flow)
- **定义**：主角被卷入一个个不同的、充满任务和危机的副本世界中求生的故事
- **核心爽点**：通关爽、获得道具爽
- **典型套路**：恐怖副本、游戏副本、电影副本
- **结构特点**：每个副本是一个小高潮
- **2024-2025 热度**：★★★★★（超级热门）
- **v5.0 推荐组合**：无限流 + 无CP + 智斗 + 悬疑

#### F. 复仇文 (Revenge Novel)
- **定义**：以主角向仇人复仇为主线的故事
- **核心爽点**：复仇爽、打脸爽
- **典型套路**：重生复仇、穿越复仇、隐忍复仇
- **情绪曲线**：憋屈期→爆发期
- **关联法则**：KB1【第三法则】的延迟满足
- **2024-2025 热度**：★★★★★（持续高热）
- **v5.0 推荐组合**：复仇文 + 重生 + 打脸爽文 + 发疯文学

#### G. 升级流 (Level-up Genre)
- **定义**：主角通过不断打怪、修炼或完成任务来提升自身实力、地位或财富的故事
- **核心爽点**：成长爽、突破爽
- **典型套路**：打怪升级、修炼突破、境界提升
- **节奏特点**：快节奏，爽点密集
- **2024-2025 热度**：★★★★☆（稳定）
- **v5.0 推荐组合**：升级流 + 系统文 + 玄幻 + 打脸爽文

### 3.3 热门设定与"梗"分类

#### A. 爽文 (Satisfying Novel)
- **定义**：泛指情节让读者感到极度畅快、满足的小说
- **核心属性**：是网络小说的核心属性之一
- **判断标准**：KB1【第三法则】的"三高"标准
- **目标**：让读者"爽"
- **2024-2025 热度**：★★★★★（永恒主题）

#### B. 屌丝逆袭 (Underdog Rising)
- **定义**：出身平凡或处于困境的主角，最终逆风翻盘，走向人生巅峰的故事
- **核心爽点**：打脸爽、认可爽
- **对比落差**：废柴→天才，穷人→富豪
- **关联法则**：KB1【第三法则】的高对比
- **2024-2025 热度**：★★★★★（经典不衰）

#### C. 废柴流 (Trash-to-Treasure)
- **定义**：开局是被人看不起的"废柴"主角，后期展现出惊人天赋并不断成长的故事
- **核心爽点**：打脸爽、成长爽
- **典型开局**：灵根被废、修为被废、天赋平庸
- **关联法则**：KB1【第三法则】的打脸五步公式
- **2024-2025 热度**：★★★★☆（经典套路）

#### D. 打脸爽文 (Face-slapping Novel)
- **定义**：主角通过展示实力或揭露真相，让曾经看不起或陷害自己的人感到震惊和后悔的情节
- **核心爽点**：打脸爽
- **执行标准**：KB1【第三法则】的打脸五步递进公式
- **频率**：每3-5章至少一次小打脸
- **2024-2025 热度**：★★★★★（永恒爽点）

#### E. 追妻火葬场 (Groveling for Forgiveness)
- **定义**：前期伤害虐待女主角的男主角，在女主角心灰意冷离开后，幡然醒悟并用尽一切方法追回的故事
- **核心爽点**：情感爽、复仇爽（女主角的）
- **典型套路**：虐妻一时爽，追妻火葬场
- **目标读者**：女性为主
- **2024-2025 热度**：★★★★★（女频超热）

#### F. 马甲文 (Secret Identity Novel)
- **定义**：主角拥有多重不为人知的强大身份（马甲），并在关键时刻逐一揭露，震惊众人
- **核心爽点**：打脸爽、装逼爽
- **信息差**：主角的真实身份是核心信息差
- **关联法则**：KB1【第一法则】的信息差管理
- **2024-2025 热度**：★★★★★（超级热门）

#### G. 真假千金 (True and False Daughter)
- **定义**：围绕身份被互换的两位女性角色展开的故事
- **核心爽点**：身份揭露、打脸爽
- **典型套路**：真千金回归、假千金下场
- **目标读者**：女性为主
- **2024-2025 热度**：★★★★★（女频超热）

#### H. 迪化文 (Misunderstanding/Deification Novel)
- **定义**：指主角的普通行为被周围人过度解读，误认为他是深不可测的绝世高人或幕后黑手的故事
- **核心爽点**：装逼爽、误会爽
- **典型套路**：主角无意为之，旁人脑补过度
- **喜剧效果**：强
- **2024-2025 热度**：★★★★☆（持续热门）

#### I. 发疯文学 ("Going Crazy" Literature)
- **定义**：主角打破常规，用不合常理但又极其直接、解气的方式应对冲突和挑衅的故事
- **核心爽点**：打脸爽、复仇爽
- **典型套路**：主角不按套路出牌，直接开大
- **节奏特点**：快节奏，爽点密集
- **2024-2025 热度**：★★★★★（新兴热门）

#### J. 虐文 (Angst Novel)
- **定义**：情节曲折，情感痛苦，旨在让读者感受到"虐心"体验的小说
- **核心情绪**：虐心、痛苦、遗憾
- **典型套路**：生离死别、误会虐恋
- **目标读者**：喜欢虐心情节的读者
- **注意**：虐文需要把握度，过度虐会流失读者
- **2024-2025 热度**：★★★☆☆（小众但稳定）

#### K. CP塑造 (Couple-focused stories)
- **定义**：以塑造和描写人物配对（CP）的互动和情感发展为核心的故事
- **核心爽点**：情感爽、互动爽
- **典型套路**：由恨生爱、步步为营、日久生情
- **目标读者**：喜欢感情线的读者
- **2024-2025 热度**：★★★★★（持续高热）

#### L. 团宠 (Group Favorite) - 2024-2025 新增
- **定义**：主角被多人宠爱、保护的故事
- **核心爽点**：被爱爽、护短爽
- **典型套路**：全家宠、全宗门宠、全世界宠
- **目标读者**：女性为主
- **2024-2025 热度**：★★★★★（超级热门）

### 3.5 v5.0 智能类型选择系统（ToT 应用）

#### 使用场景
当用户不确定选择什么类型时，系统可以使用 Tree of Thoughts（思维树）生成多个候选方案，并进行评估。

#### 执行流程
```
Step 1: 收集用户需求信息
- 目标读者（男/女/全年龄）
- 偏好节奏（快/慢）
- 核心爽点偏好（打脸/情感/成长/智斗）
- 是否要感情线（有CP/无CP）

Step 2: 使用 ToT 生成 3 个候选类型组合
候选A: [主类型] + [流派] + [梗] + [背景]
候选B: [主类型] + [流派] + [梗] + [背景]
候选C: [主类型] + [流派] + [梗] + [背景]

Step 3: 对每个候选进行三维评估
- 商业潜力（0-10分）：基于 2024-2025 市场热度
- 创新性（0-10分）：组合的新颖程度
- 可执行性（0-10分）：创作难度和用户能力匹配度

Step 4: 向用户展示评估结果，推荐最优方案
```

#### 示例：用户需求"女频、快节奏、打脸爽"

**候选A：都市 + 重生 + 马甲文 + 娱乐圈**
- 商业潜力：9分（都市重生和马甲文都是超热门）
- 创新性：6分（组合较常见）
- 可执行性：8分（套路成熟，易上手）
- 总分：23分

**候选B：古言 + 穿书 + 真假千金 + 宫斗**
- 商业潜力：9分（穿书和真假千金都是超热门）
- 创新性：7分（组合较新颖）
- 可执行性：7分（需要一定的古代背景知识）
- 总分：23分

**候选C：无限流 + 无CP + 发疯文学 + 悬疑**
- 商业潜力：10分（无限流和发疯文学都是新兴超热门）
- 创新性：9分（组合非常新颖）
- 可执行性：6分（无限流副本设计难度较高）
- 总分：25分

**推荐**：候选C（总分最高），但需要提醒用户无限流的副本设计难度较高，如果是新手可以选择候选A或B。

#### 冲突检测
系统会自动检测类型组合中的冲突：
- ❌ 无CP + 总裁文（总裁文核心是感情线）
- ❌ 种田文 + 快节奏（种田文通常是慢节奏）
- ❌ 虐文 + 爽文（虐和爽是相反的情绪）
- ✅ 重生 + 复仇文（完美组合）
- ✅ 系统文 + 升级流（完美组合）
- ✅ 穿书 + 炮灰逆袭（完美组合）

### 6.1 ToT 智能类型选择系统

#### 功能描述

#### 执行流程
```
Step 1: 收集用户需求信息
- 目标读者（男/女/全年龄）
- 偏好节奏（快/慢）
- 核心爽点偏好（打脸/情感/成长/智斗）
- 是否要感情线（有CP/无CP）

Step 2: 使用 ToT 生成 3 个候选类型组合
候选A: [主类型] + [流派] + [梗] + [背景]
候选B: [主类型] + [流派] + [梗] + [背景]
候选C: [主类型] + [流派] + [梗] + [背景]

Step 3: 对每个候选进行三维评估
- 商业潜力（0-10分）：基于 2024-2025 市场热度
- 创新性（0-10分）：组合的新颖程度
- 可执行性（0-10分）：创作难度和用户能力匹配度

Step 4: 向用户展示评估结果，推荐最优方案
```

## 十、【常见问题与解决方案】

### Q1: 如何选择最适合自己的类型组合？

**A1**：使用 ToT 智能类型选择系统
1. 先收集自己的需求信息（目标读者、偏好节奏、核心爽点）
2. 让系统生成 3 个候选方案
3. 根据评估结果（商业潜力、创新性、可执行性）选择最适合的

### Q2: 模板如何灵活使用，不会太死板？

**A2**：模板是框架，不是限制
1. 模板提供的是结构和思路，不是具体内容
2. 可以根据自己的创意调整模板
3. 可以组合多个模板元素，创造独特的设定
4. 参考成功案例，学习如何灵活运用

### Q3: 如何确保不违反内容限制？

**A3**：使用智能检测系统
1. 生成内容后自动扫描，检测禁用元素
2. 发现问题时，系统会提示并建议修正
3. 如果是例外情况，系统会使用 CoT 推理是否允许
4. 记录用户的临时许可，避免重复询问

### Q4: 如何追踪最新的市场热点？

**A4**：使用市场热点智能追踪系统
1. 定期查看【市场热点追踪】章节
2. 关注热度评级（★★★★★ 表示超热门）
3. 了解读者偏好变化，调整创作方向
4. 参考趋势预测，提前布局未来热点

### Q5: 类型组合出现冲突怎么办？

**A5**：使用冲突检测和调整
1. 系统会自动检测类型组合中的冲突
2. 发现冲突时，系统会提示并建议调整
3. 可以删除冲突的元素，或者寻找替代方案
4. 使用 ToT 生成新的候选方案
