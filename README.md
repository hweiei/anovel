本目录存放小说语料库相关的提示词模板、片段示例与记忆体（Memory）模板。

## 文件说明

| 文件 | 说明 |
|------|------|
| `01_预料库提取提示词模板.txt` | 预料库片段提取提示词模板，定义片段结构范式（TEXT + META + CONFLICTS） |
| `迭代300_主提示词.txt` | 主提示词：Frankentexts 章节生成模块（融合拼接生成）完整流程 |

> 压缩包内的文件已同时解压为 `知识库/` 下的 Markdown，便于在 GitHub 上直接阅读与版本对比。

## 知识库编号约定

- **1–8 号**：预料库（通用碎片库，来自多部已授权小说与公共合规语料；并非定向某一部小说）
- **9 号**：世界观记忆体（World Memory）— G/E/M/＋ 四段式
- **10 号**：人物记忆体（Character Memory）— 角色卡字段制
- 9 / 10 始终视为**最高优先一致性来源（SSOT）**，可随时替换与更新

## 生成约束摘要

- 章节正文约 **92%** 直接拼接自 1–8 号预料库，约 **8%** 为原创（仅用于连接、过渡与最小改写以消除冲突）
- 每章覆盖 **≥5 个**不同预料库；单一预料库贡献 **≤30%**
- 设定冲突时一律以 9 / 10 为准；允许改动仅限命名/术语替换 + 最小改写（计入 ≤8%），否则弃用该片段
- 目标平台版式：番茄小说（短句倾向、自然换行、空行分段、弱格式化）
- 单章 ≥3000 字，全书 50 万字量级对应 160–170 章
